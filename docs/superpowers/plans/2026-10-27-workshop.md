# ROSCon MicroDuck Workshop Implementation Plan

> **For agentic workers:** Use the task's bounded implementation brief and test-driven development. Implementations use isolated ownership and are reviewed before integration.

**Goal:** Publish a usable two-hour ROSCon ES MicroDuck workshop on the instructor's personal GitHub by 08:30 Europe/Madrid on 27 October 2026.

**Architecture:** Isaac Lab 3.0 owns one Newton simulation and the learned policy. A ROS 2 Lyrical gateway publishes real sensor data and owns the bounded command channel. Isaac ROS 5.0 processes onboard camera images. A real CASCADE agent consumes allowlisted perception and invokes bounded ROS tools. A separate evaluator checks physical outcomes.

**Tech Stack:** Python 3.12, Isaac Sim 6.2.0.0, Isaac Lab v3.0.0, Newton, ROS 2 Lyrical, Isaac ROS v5.0.0, CASCADE, NVIDIA Brev with L40S or RTX PRO.

**Spec:** `docs/superpowers/specs/2026-10-27-workshop.md`; later explicit user choices override provisional text: Isaac ROS 5.0, Brev only, one-day credits, public GitHub delivery by 08:30.

## Global constraints

- Newton only; no PhysX/MJLab runtime substitution. Public GA sources, exact runtime receipts.
- No private robot assets/checkpoints, secrets, internal hosts or machine-specific paths in the public project.
- Public Pollen assets and models are pinned and fetched separately; software and mesh licenses remain distinct.
- Real ROS traffic, real Isaac ROS image processing and a real local CASCADE brain for end-to-end acceptance. Mocks are CPU test fixtures only.
- No simulator poses, GT detections or external-camera localization in policy/navigation/agent inputs. GT is evaluator-only.
- One simulation-thread actuator owner. Reject malformed/unsafe commands, stale episodes/generations, stale perception and uncertain retries. Priority stop and wall watchdog remain independent of the model.
- English code and public materials. A short training exercise is not a claim of converged walking.
- Do not provision paid Brev instances, operate physical robots, modify unrelated SDK environments or change drivers.
- Preserve failure evidence. Publish explicit readiness status if any layer is still blocked at the deadline.

## Shared interfaces and ownership

Package root is `src/microduck_workshop`. Parent owns packaging, provenance download, common contracts, README, curriculum, tests/CI and publication. Runtime worker owns `sim/` and `policy/`. ROS worker owns `ros_ws/`, `docker/`, `compose.yaml` and Brev setup scripts. CASCADE worker owns `agent/` and capstone exercise/solution files. No worker may change another owner's files or publish.

The simulation exports a loopback-only HTTP transport on port 8766 (not a ROS substitute for the student-facing gateway). `/v1/health` reports actual runtime identity; `/v1/state` exposes timestamped joint/IMU sensor data; `/v1/camera` returns actual head RGB JPEG with atomic source sequence/time metadata; `/v1/camera_info` returns matching calibration; `/v1/overview` is human visualization only. `/v1/command`, `/v1/renew`, `/v1/stop` and `/v1/status/<request_id>` implement the common command/receipt contract. Detailed world-state evaluation never appears in agent-facing observations.

Commands use `episode_id`, `request_id`, `expected_generation`, `vx`, `vy`, `wz`, `duration_s`. Conservative initial lesson envelope: |vx|<=0.10 m/s, vy=0, |wz|<=0.30 rad/s, 0<duration_s<=2.0 s. Validate booleans, types, nonfinite values and unknown fields. Commands have a separate monotonic wall lease (0.5 s, renewed by the owner), expire on simulation time, and are invalidated by a latched emergency stop. Status separates accepted, executing, completed and independently verified. No automatic retry after an uncertain motion send.

The ROS gateway wraps the transport with real ROS services and telemetry topics under `/workshop/microduck`, ROS_DOMAIN_ID configurable. The CASCADE domain uses those ROS services, never calls the simulator directly. It exposes `microduck.observe`, `microduck.walk_bounded`, `microduck.verify`; composed runtime owns emergency_stop/task_done. `reset_stop` is operator-only. Perception is age-checked and allowlisted from real Isaac ROS output.

## Review focus

- Changed ROS 2 distribution or Python ABI must not silently load Jazzy libraries into a Lyrical process.
- Old detector messages must not become fresh merely because a subscriber received them recently.
- A paused/stalled simulation or blocked LLM cannot preserve an expired nonzero command.
- Upstream MJLab policy shape matching alone cannot certify actuator, delay, gravity-estimator or stopping fidelity.
- Brev documentation must distinguish container shutdown from stopping cloud billing; no invented launchable URL.
