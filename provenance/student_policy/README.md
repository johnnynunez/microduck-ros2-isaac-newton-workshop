# Student-policy evidence

These are historical, source-bound receipts from real GPU0 Isaac Lab/Newton executions, not synthetic test outputs. The four files listed in [`../public_redaction_manifest.json`](../public_redaction_manifest.json) are **public, path-sanitized copies**, not byte-identical raw receipts. They establish a bounded native skill on their recorded sources, **not full ROS/perception/CASCADE acceptance, locomotion convergence, or validation of later source revisions**.

## Publication redaction and artifact identity

Only the original host checkout prefix was replaced with `${WORKSHOP_ROOT}`. Every suffix, metric, numeric value, timestamp, verdict, checkpoint identity, source hash and failure message (apart from paths) is preserved. The marker denotes the historical project root, including worktree and local-runtime suffixes; it does not turn historical launch commands into executable instructions. The manifest records each original SHA-256, published SHA-256, replacement count and changed JSON pointer. Raw originals were archived privately, outside Git, before redaction; exact reverse-byte substitution and JSON logical equivalence were verified against those originals.

**This public snapshot is NONDEPLOYABLE.** `policy_manifest.json`, `attempt01_policy_manifest.json` and both admission records retain their original artifact bindings, without rehashing them to authorize sanitized files. In particular, each policy manifest's training-receipt SHA-256 identifies the private original, not the differently hashed public copy. Portable publication checks must verify the public copy against `published_sha256` and compare historical references against `original_sha256`. This publication manifest is not trusted runtime input, cannot bypass artifact or source validation, and does not prove physical acceptance on current sources. Runtime validators must continue rejecting any byte-mismatched bundle.

Actual notebook runs create their own complete, unredacted local bundles and must pass the normal runtime identity and admission checks. Do not copy these sanitized historical files into a live bundle. To publish another run, first preserve its raw bytes and hashes privately, redact only its confirmed checkout prefix, verify byte-level and JSON equivalence, and add a new dual-hash manifest entry. Never replace historical source hashes with current hashes or rewrite earlier run evidence to claim a fresh result.

## Historical evidence

- `training_receipt.json`: public v8 actor-only warm-start; fresh critic and Adam; 512 native physics steps, four PPO updates, sixteen optimizer steps. The saved checkpoint's actual updated actor was exported. Normalization remains frozen. Import/export parity uses all 128 recorded native observations.
- `policy_manifest.json`: binds the checkpoint, export, training receipt, action mode and control sources. This directory is an evidence snapshot, **not a deployable artifact bundle**: weights and raw local run files are intentionally not committed. Students generate their own complete run directory.
- `admission.json`: eight step/resume checks and four zero/rest controls, all evaluated with unchanged `evaluate_motion`. The explicit `step-forward-v1` contract remains .10 requested peak, .25 neural drive for one simulation second, one second zero, and completion plus .36 seconds of independent verification. It is not a general constant-velocity calibration.
- `native_handoff.json`: the exported student policy served through the real native HTTP owner. Two steps passed; observation-proof expiry, independent lease expiry and priority STOP refused further motion as expected. Live health identified the same policy, manifest and admission. These diagnostic proofs used original native sample timestamps, not fabricated ROS observations.
- `../native_policy_default_revalidation.json`: the unchanged canonical default policy also passed a fresh native HTTP confirmation with the new explicit-selection code. Existing historical receipts were not rewritten.
- `attempt01_*`: preserved first attempt. Physical holdouts passed, but Kit teardown exited before the final admission write, leaving `passed:false`. It remains unadmitted. The corrected implementation finalizes inside the runtime context and uses an outer process to read back and recompute physical checks before declaring success.

The successful student actor is `d997842181623f1ce030d86cb815f0aa954d29f8f7bdbad0073cd50f236139a2`, distinct from public initializer `2fc7f8ee6acd7d0d3f66a99927b5d5a56589aeed02ec714de329b252d5ccf492`. A later training run can legitimately produce different weights and requires its own admission; these receipts never authorize another policy.

Raw transition, policy and evaluator traces are retained in the local run directories with hashes in these receipts. Portable tests verify receipt consistency; the optional `test_student_live_artifacts.py` suite also reads the complete local bundles and recomputes the frozen physical gates. Neither test suite substitutes for a fresh native execution after control-source changes.
